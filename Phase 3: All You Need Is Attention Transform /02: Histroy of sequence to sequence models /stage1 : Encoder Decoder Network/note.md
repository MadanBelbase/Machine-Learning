in this stage of  history , researcher publish the  papaer called Encoder Decoder Network in 2014 by Ilya Sutskever, Oriol Vinyals, and Quoc V. Le. This paper introduced the concept of using two separate neural networks, an encoder and a decoder, to perform sequence-to-sequence tasks such as machine translation. The encoder processes the input sequence and encodes it into a fixed-length vector representation, while the decoder takes this representation and generates the output sequence. This architecture laid the foundation for many subsequent advancements in natural language processing and machine translation. But in this there is a problem  with decoder, In decoder  the output generated at each time step is only based on the fixed-length vector representation from the encoder, which can lead to information loss, especially for long input sequences. This is because the fixed-length vector may not capture all the relevant information from the input sequence, making it difficult for the decoder to generate accurate outputs. This issue is often referred to as the "bottleneck" problem in sequence-to-sequence models. 

the output generated by encoder is store on the  context vector (also known as the thought vector), which is a fixed-length vector representation of the input sequence. The decoder then uses this context vector to generate the output sequence. However, since the context vector is fixed-length, it may not be able to capture all the relevant information from the input sequence, especially for long sequences. This can lead to information loss and make it difficult for the decoder to generate accurate outputs. To address this issue, researchers have developed various techniques such as attention mechanisms, which allow the decoder to focus on different parts of the input sequence at each time step, rather than relying solely on the fixed-length context vector.
