# 200 Days Machine Learning Roadmap: From Zero to Advanced

This roadmap guides absolute beginners (zero-level knowledge) through machine learning (ML) over 200 days, assuming 1-2 hours of daily study/practice. It progresses from foundational skills (math, programming) to core ML concepts, deep learning, and advanced topics, including research papers. Given your interest in tracking learning journeys (from your learning challenge website idea), you can integrate this roadmap into a GitHub-connected platform to monitor progress and send notifications.

**Key Guidelines:**
- **Daily Structure:** Each day includes:
  - **Theory:** Videos/readings (free resources).
  - **Practice:** Coding exercises (use free platforms like Google Colab, Kaggle Notebooks).
  - **Resources:** All free; links provided.
- **Tools Needed:** Free Google account for Colab, GitHub for version control (learn basics early). Create a repo to track your ML projects, aligning with your goal of GitHub integration for progress tracking.
- **Tracking Progress:** Maintain a GitHub repo for notebooks. Join free communities: Reddit r/MachineLearning, Kaggle forums. Optionally, log daily progress in a custom website (like your SlotSwapper project structure, using React/TypeScript).
- **Research Papers:** Introduced from Day 100; read abstracts first, then full papers via arXiv (free). Use Papers with Code for implementations.
- **Pacing:** Revisit tough topics. Take breaks every 30 days.
